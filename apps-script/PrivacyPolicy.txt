## 5. Torn API Keys

Certain Bot features may require a Torn API key or similar authorisation.

Where an API key is provided:

* it will only be used for authorised Bot functionality;
* it will not intentionally be exposed publicly;
* it will not be sold;
* it will not be used to obtain information unrelated to the Bot's functionality; and
* access should be restricted to the minimum level reasonably required.

Where API keys are stored, appropriate technical measures should be used to protect them.

You should never provide your Torn account password to the Bot.

If you believe an API key has been compromised, you should revoke or replace it through Torn as soon as possible.

### API Key Retention

API keys should only be retained for as long as necessary to provide the feature for which they were supplied.

Where supported, unlinking your account or requesting deletion will remove the stored API key from the Bot's active systems.

Some information may temporarily remain within encrypted backups until those backups are automatically rotated or deleted.
